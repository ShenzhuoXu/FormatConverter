FormatConverter 尚未启动

本页面只是一个说明页，不是应用入口，也不代表服务已经运行。 它不会调用任何接口，也不需要你填写任何内容。请先启动本地服务，再访问 http://127.0.0.1:8765/ 使用图形界面。

如何启动

  1. 双击仓库根目录下的 启动图形界面.bat。
    脚本会自动选择 Python、检查依赖、启动服务，并打开默认浏览器。
    启动后请保留弹出的黑色窗口（它就是服务窗口），按 Ctrl+C 可停止服务。
  2. 或在命令行（终端）中手动执行： 
    python -m format_converter.web_server

前置条件

  • Python 3.11 或更高版本。
  • 在仓库根目录安装依赖（首次使用）： 
    python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt

说明

  • 服务只监听本机 127.0.0.1，不会暴露到公网。
  • 如果浏览器已打开但页面仍显示“尚未启动”，请稍等片刻或刷新页面。
  • 若端口 8765 被其它程序占用，脚本会自动改用相邻的空闲端口，并给出提示。
