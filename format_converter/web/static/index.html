FormatConverter

本地 PDF → Markdown 转换与清理工具，全部任务在本机回环地址上运行。

网络 / 隐私 / 费用提示

  • 除「AI 校对」外的所有任务只在本机处理，上传内容不会离开你的电脑。
  • 「AI 校对」会把你选择的 Markdown 内容以真实网络请求发送到第三方服务 OrcaRouter，可能产生费用，费用由你自己的 OrcaRouter 账户承担。请确认内容适合发送到第三方后再使用。
  • 本页面不会采集或保存任何 API Key；Key 只由服务器的环境变量 ORCAROUTER_API_KEY 提供。
  • 本页面不使用任何本地持久化存储，也不加载第三方脚本 / 样式 / 字体 / 图片；运行结果仅在本页生成下载链接。

① PDF 转 Markdown

上传一个 PDF 文件，转换结果为 Markdown，打包为 ZIP 供下载。

② Markdown 清理

上传一个 Markdown 文件，清理重复段落、合并被折行的段落并保留列表，结果打包为 ZIP。

③ 转换后清理流水线

上传一个 PDF 文件，先转换为 Markdown，再执行清理，结果打包为 ZIP。

④ AI 校对

把单个 Markdown 文件发送到 OrcaRouter 做 OCR 纠错与 Markdown 排版修正。

Provider OrcaRouter
环境变量 Key 检测状态

Key 由服务器环境变量 ORCAROUTER_API_KEY 提供，本页面不采集。

本页面与任务 API 同源运行；无外链脚本 / 样式 / 字体 / 图片，无遥测，无本地存储。
